# R0-WS2-013 — service-ci.yml also fetches platform-lib-go

Written retroactively: this story's own code shipped on 2026-10-04 as
`platform-workflows@ebf0710`, before this spec existed. Found already done during
S3 planning — a backlog bookkeeping gap, not a code gap — and this spec backfills
the record rather than leaving the story done with no written account of it.

## What this story built

`service-ci.yml`'s existing "Private module access" step (R0-WS2-008's own, originally
`platform-contracts`-only) generalised to also rewrite `platform-lib-go` via a
`PLATFORM_LIB_GO_READ_TOKEN` secret:

```bash
if [ -n "$PLATFORM_LIB_GO_READ_TOKEN" ]; then
  git config --global "url.https://x-access-token:${PLATFORM_LIB_GO_READ_TOKEN}@github.com/sdlc-a2z/platform-lib-go.insteadOf" "https://github.com/sdlc-a2z/platform-lib-go"
  private="${private:+$private,}github.com/sdlc-a2z/platform-lib-go"
fi
```

Each credential is independent and silently no-ops when its own secret is not set —
a caller importing neither, one, or both of `platform-contracts`/`platform-lib-go`
pays nothing extra either way. Shipped as `service-ci.yml@v4`.

## Real evidence, not asserted

`identity-service` is a real consumer that imports both `platform-lib-go` (directly)
and, transitively, `platform-contracts` (ADR-0010's own stated transitive
dependency) — confirmed from its own `go.mod`. Its `ci.yml` pins `service-ci.yml@v4`
with no per-repository special-casing, and its real `component`/`build` jobs pass
(`gh run list` against `identity-service`, checked live during S3 planning, not
assumed from the diff alone) — the only failing job on its recent runs is an
unrelated image-push step blocked on GCP billing, a separate, already-named gap.

## What this deliberately does not do

- This spec documents code that already shipped; it adds no new behaviour.
- `service-template-go`'s own generated `ci.yml.tmpl` was found, separately during
  S3 planning, still pinned to `service-ci.yml@v1` — predating this story's own
  `@v4` fix, so every newly generated service would have hit the same gap this
  story closed for existing callers. Fixed in `service-template-go@21388ac`, a
  different repository's own story, not this one's.

## Definition of Done

Met, and has been since 2026-10-04 — this spec exists to say so in writing, not to
reopen or re-verify work that was already real.
